Patterns

Two questions the raw counts cannot answer: which offences concentrate where, and which offences move together.

Offence concentration by area

Colour is a location quotient — an offence's share of that area's caseload divided by its share nationally. Red means over-represented, blue under-represented. Population plays no part, so size does not distort it. Hover any cell for the figure.

Which offences move together

Correlation across all area-months, after standardising each offence within each area — so this is co-movement, not "big places have more of everything".

Correlation is not causation. Two offences can move together because one drives the other, because both follow something else, or simply because both reflect how much was being recorded that month.

Data & method

What this is built from, how it was checked, and what it cannot tell you.

Source and verification

Police Headquarters publishes one scanned sheet a month. There is no text layer — the numbers exist only as pixels — so every figure here was read off an image.

Each sheet over-determines itself: every row prints a Recovery sub-total and a grand total, and the bottom row totals every column. That is 53 independent arithmetic checks per sheet. A transcription is accepted only when all 53 balance to zero residual.

Corrections on the record

The 2020–May 2025 figures came from an earlier compilation that had itself been OCR'd. Every defect found in it was re-read from the original PDF and is listed here rather than quietly patched.
